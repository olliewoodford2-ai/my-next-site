# Reference study

The required references were checked with live HTTP requests on 4 November 2026 and returned reachable responses: Pear, Obys, Active Theory, Lusion, Locomotive and Hello Monday. The supplied Maison Aurelle and Private Aviation URLs also returned reachable responses.

Transferable principles used here:

- Editorial display type should carry the opening rather than compete with the 3D layer.
- Chapter-like pacing benefits from quiet holds and concise technical metadata.
- Immersive work should use depth, material and atmosphere as a system rather than decorative effects.
- Scroll transitions should be directional but reversible, with content remaining usable as ordinary HTML.
- Project presentation should preserve a strong visual frame while keeping the title and outbound action legible.

DIVINUM-specific interpretation: Flecha display roles, GT Standard body/mono roles, scene-aware atmospheric colour, one-shot editorial reveals, and restrained hover depth were added without copying any reference branding, assets or layout.
